# 📘 Curso OO – Full Cycle

Este repositório contém os códigos desenvolvidos durante o **Curso de Orientação a Objetos da Full Cycle**.

O objetivo do projeto é **praticar e consolidar conceitos de Orientação a Objetos**, aplicando boas práticas de desenvolvimento e organização de código, utilizando **TypeScript**.

O conteúdo aqui presente é voltado para fins **educacionais**, acompanhando os exemplos e exercícios propostos ao longo do curso.

---

## 🧠 Conceitos abordados

- Orientação a Objetos
- Classes e objetos
- Encapsulamento
- Herança
- Polimorfismo
- Boas práticas de código
- Organização e estrutura de projetos

---

## 🛠️ Tecnologias

- **TypeScript**
- **Node.js**

## 🎓 Curso

Curso de **Orientação a Objetos** oferecido pela **Full Cycle**.
